# Controle Bancário em Python

Programa simples de terminal que simula um controle bancário.

## O que ele faz
- Consultar saldo
- Depositar valores
- Sacar valores

## Validações
- Não aceita depósito ou saque com valor zero ou negativo
- Não permite sacar mais do que o saldo disponível

## Como rodar
1. Tenha o Python 3.10 ou superior instalado
2. Baixe o arquivo `controle_bancario.py`
3. No terminal, execute: `python controle_bancario.py`
